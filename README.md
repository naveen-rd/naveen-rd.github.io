# naveen-rd.github.io

Professional site for Naveen Raj Dhanapal. Static HTML, CSS, and a few lines of JavaScript. GitHub Pages serves it from the repository root.

Once this repository is public and named `naveen-rd.github.io`, the site is at [https://naveen-rd.github.io](https://naveen-rd.github.io).

## Publish

1. Create a public repository named `naveen-rd.github.io` on the `naveen-rd` account.
2. Push this folder to the `main` branch.
3. In the repository, open Settings → Pages → Build and deployment, and choose Deploy from branch `main` at `/`.

## Local preview

```bash
python3 -m http.server 4173
```

Open http://127.0.0.1:4173.
